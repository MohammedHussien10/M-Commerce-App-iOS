## M-Commerce App - Genie Store

## Overview

- Genie Store is a modern mobile M-Commerce application that provides users with a seamless and personalized shopping experience. The app allows users to browse products by categories and brands,      manage their shopping cart, save favorite items, manage their profile, and checkout securely with multiple payment options.

## Architectural Design Pattern
  - MVVM + UseCase + Repository Pattern,Remote

## Clean separation between:

  - View (SwiftUI)

  - ViewModel (Business Logic)

  - UseCase (Application Logic)

  - Repository (Data Layer)

  - RemoteDataSource (GraphQL / Firebase APIs / UserDefaults)

## Technologies & Libraries

  - Area	Technologies / Tools
  - Language	Swift
  - UI Framework	SwiftUI
  - State Mgmt.	Combine
  - Database	Core Data
  - Networking	Apollo Client + GraphQL
  - Authentication	Firebase Authentication
  - Media Handling	Kingfisher (Image Caching)
  - API Backend	Shopify Storefront API
  - Testing & Tools	Postman, Shopify GraphQL Explorer

## Key Features

  Authentication: Email, Google, or Anonymous sign-in with Firebase.

  Product Discovery: Browse products by category and brand with detailed product info.

  Favorites: Save products for later.

  Cart & Checkout:

   - Smart cart management with real-time updates.

   - Secure checkout using Shopify Draft Orders.

   - Apply discount codes.

  Profile Management:

   - Manage saved addresses.

   - View order history.

   - Update user profile.

  Admin Info: About us and contact us sections inside the app.

  Use Swift Package Manager for Apollo, Firebase, Kingfisher, etc.

  Configure Shopify API credentials and Firebase.

  Run the project in Xcode.
